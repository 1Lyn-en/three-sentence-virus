# 三句话病毒 Skill

这是一个供 AI Agent 加载和执行的中文叙事 Skill，不是提示词合集，也不是普通写作教程。它把可复用的社会心理学机制、写作流程、质量检查和事实安全规则封装为一套完整能力。

你即将使用的不是单一写作风格，而是一套**传播心理触发器**。

一篇文章被读完、记住、转发，靠的不是辞藻，而是一连串心理机制：反差让大脑停顿，缺口让读者发痒，高唤起情绪驱动分享，留白让人难忘，模因句式被复制。你的任务是把这些触发器编码进叙事里，让读者停不下来。

核心哲学：**永远不要告诉读者该怎么感受。你只负责摆事实、给细节、留空白。情绪是读者自己长出来的。** 越是要紧的时刻，越要退后一步，用一个无关紧要的细节完成那一击。

需要详细原理时读 `references/triggers.md`；需要技法正例反例时读 `references/style-anatomy.md`；涉及真实事件、公众人物或网传素材时必须先读 `references/safety.md`。

## 工作流程

### 1. 素材分层（动笔前必须做）

先把用户给的素材分成四类并标记：
- **已确认事实**：有可靠来源或用户明确亲历
- **单方陈述**：只有一方说法，对方未确认
- **网传/未经证实**：来源不明或仅在社交媒体流传
- **虚构素材**：用户明确说是创作

只有"已确认事实"和"虚构素材"可以直接使用具体数字。单方陈述和网传内容必须模糊化处理或标注来源，不得替当事人编造细节。详见 `references/safety.md`。

### 2. 选择触发器

12 个触发器不必全用。根据素材从四层中各选 1-3 个，全文通常 5-8 个：

| 层 | 触发器 | 一句话用法 |
|---|---|---|
| 注意力 | 反差锚定 | 开头三句并置两个极端尺度，第三句建立关系 |
| 注意力 | 好奇缺口 | 给信息但不给完整答案，让缺口自己咬人 |
| 注意力 | 节奏控制 | 短-短-短-长-短，对话不超过两句 |
| 情绪 | 情绪唤起 | 选震惊/荒诞/心疼节点，不选平静/满足 |
| 情绪 | 反高潮 | 铺得越大，落得越小，落点越日常 |
| 情绪 | 社会比较 | 排场细节满足窥视，但不解释其意味 |
| 记忆 | 留白未完成 | 关键处沉默，人物不知道就停在不知道 |
| 记忆 | 具象降维 | 用物件、数字、动作替代一切情绪形容词 |
| 记忆 | 回环闭合 | 结尾回到开头意象，意义已经不同 |
| 传播 | 模因句式 | 埋 3-5 个可独立截屏的短句 |
| 传播 | 旁观者镜头 | 让无关者的日常动作照见主线 |
| 传播 | 元叙事掩护 | 文末列出本文触发了哪些心理机制 |

### 3. 写反差开头

前三句话必须完成：一个极轻/极小/极日常的事物，一个极重/极大/极公共的事物，第三句把两者勾连。不铺垫、不背景介绍、不"事情要从XX说起"。

### 4. 沉到场景里

选 2-3 个关键场景，每个场景写 300-800 字。写动作的步骤、物件的触感、环境的声音、数字的精确。不要一个段落展示一个技法——技法要融化在叙事里。

### 5. 留白与回环

关键情感处不解释。人物不知道的答案不要替他知道。结尾必须回扣开头的意象、物件或句式，但因为读者已经读完，同一句话的重量完全不同。

### 6. 提取模因金句

从全文中挑出 3-5 句可以独立截屏传播的短句。它们必须脱离上下文也成立，且有节奏感。

### 7. 生成元说明

列出本文实际使用了哪些触发器，每个对应什么心理学原理。这份元说明是传播的二次燃料——它让转发者可以说"我在研究叙事心理学"而不是"我在吃瓜"。

## 写作铁律

1. **能让动作说话，就不解释心理。** 不写"我很难过"，写"我把工牌放在桌上，正面朝下"。
2. **能让数字说话，就不用形容词。** 不写"很多钱"，写"四百三十二块"。但数字必须真实，记不清就写记不清。
3. **能让物件说话，就不总结感情。** 物件要普通、具体、可触摸，越不起眼越好。
4. **能让前文回来一次，就不重新抒情。** 伏笔不举牌子，照应不解释含义。
5. **对话不超过两句。** 说完就换段。"我说好。"可以独立成段。
6. **感叹号全文为零。** 省略号不用来制造"此处无声"，用句号。
7. **不写"那一刻我终于明白了"。** 不写"也许这就是"。不写"我不知道该如何形容"。
8. **`---` 分隔符全文不超过 6 个。** 场景之间换段落，阶段之间才用分隔符。
9. **技巧不能比人物先被看见。** 如果读者先注意到技法，删掉最显眼的那一个。

## 语言禁区

- "仿佛""好像""似乎"用于情感比喻（物理观察可用）
- "内心深处""灵魂""挣扎""煎熬""心碎""撕裂"
- "岁月如歌""时光荏苒""物是人非"及一切四字成语抒情
- "在那一刻，我忽然明白了……"
- "也许，这就是……"
- "我不知道该如何形容那种感觉"
- 排比抒情句
- 感叹号

## 输出格式

按以下顺序输出：

1. **标题备选 ×3**：每个标题自带好奇缺口或反差
2. **正文**：完整长文
3. **可截屏金句 ×3-5**：独立列出
4. **触发器元说明**：列出本文使用的触发器及对应心理学原理，格式为"触发器（原理）：本文如何使用"

如果用户只要求改写片段而非完整长文，可只输出改写结果，但仍需遵循上述写作铁律。

## 安全边界

- 不编造数字、时间、金额、人物身份或事件顺序
- 不模仿任何在世真人的口吻、身份或标志性措辞
- 不提供受版权保护的原文全文
- 涉及私人生活细节时只做技法层面的处理，不扩散、不脑补
- 真实事件必须标注哪些是已确认事实、哪些是单方说法
- 生成内容默认标注为创作或娱乐用途

详见 `references/safety.md`。
